# Weibo HarmonyOS SDK

`core.har` is the official Weibo HarmonyOS OpenSDK distributed by Beijing
Weimeng Innovation Technology Co., Ltd.

- Package version: `25.4.0`
- Upstream SDK release: `harmony_weibosdk_25.4.0.zip`
- Source: <https://open.weibo.com/wiki/SDK>
- License declared by the HAR: `Apache-2.0`
- SHA-256: `7fe3b9f5d5b176637fb9730d2814177a76f0edcbf19081090345b6c41d573f91`

The binary is kept unchanged so Flutter applications can consume the official
Bytecode HAR without an external OHPM dependency.
